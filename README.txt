VESPER AI · Meta App Review Policy Pages
=====================================

Included:
- index.html: public landing page
- privacy-policy.html: privacy policy
- data-deletion.html: deletion instructions
- style.css: responsive website styles

REQUIRED BEFORE PUBLISHING:
1. Contact email is set to abhinaviit2026@gmail.com; this address will be visible publicly. Confirm it is monitored.
2. Review statements against the real VESPER code, especially third-party AI processing, storage, retention, security, and deletion functionality. This draft is based on project descriptions and not a direct code audit.
3. Update the effective date if the content changes materially.
4. Set up a way to honor deletion requests, including verification and record removal.

HOST FREE ON GITHUB PAGES:
1. Create a PUBLIC repository e.g. vesper-privacy-policy.
2. Upload the four web files (not this README if not desired) to the repository root.
3. Repository Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Confirm the live privacy-policy.html URL loads without login on a private/incognito browser window and copy it into Meta App Review's Privacy policy URL field.
5. The live data-deletion.html URL can be used for Data Deletion Instructions where Meta requests it.

No API keys, OAuth credentials, or private messages belong in this public repository.
